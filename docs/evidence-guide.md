# 근거 자료 추가 방법

현재 화면은 `별도 자료 준비 중`으로 표시합니다. 경험의 수행 내용은 사용자 설명이며 별도 산출물 검증은 아직 하지 않았습니다.

1. 공개 가능한 이미지·PDF를 `public/evidence/`에 넣거나 공개 프로젝트 URL을 준비합니다. 이메일·실명·전화번호와 타인의 정보, 비밀값, 이미지 메타데이터를 먼저 점검합니다.
2. `index.html`의 `#evidence` 안에 있는 `.evidence-links` 목록에 항목을 추가하고 `hidden` 속성을 제거합니다. 관련 경험 01/02/03, 자료 제목과 형식을 링크 텍스트에 명시합니다.
3. 준비 중 문구는 실제 공개된 자료 범위에 맞게 바꿉니다. 새 탭이 필요하지 않으면 같은 탭에서 열고, 새 탭이면 `rel="noopener noreferrer"`를 지정합니다.
4. `npm test`와 `npm run build` 후 두 기준 해상도를 재검사합니다. 자료를 추가하면 첫 화면 높이가 바뀔 수 있습니다.
5. 배포한 자료와 소스 URL을 시크릿 창에서 확인하고 요구사항 C09 및 배포 기록을 갱신합니다.

예시 구조 (실제 파일이 있을 때만 적용):

```html
<li><a href="./evidence/kiosk-ui.png">경험 01 · 키오스크 UI 화면 (PNG)</a></li>
```

원본 자료를 공개 저장소에 먼저 올린 뒤 가리는 방식은 사용하지 않습니다. 삭제한 자료는 재빌드 시 dist에서도 제거됩니다.
