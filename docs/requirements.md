## 제출 화면의 추가 조건

- 공개 결과물 URL과 소스 URL은 필수.
- 소스는 브랜치나 저장소 첫 화면이 아니라 전체 소스를 받을 수 있는 40자리 또는 64자리 소문자 full commit 포함 HTTPS 고정 URL.
- 확인 파일은 선택. 확인법 4줄과 판단 3줄은 권장 형식이지만 비워 두면 후행 평가에서 기록 없음으로 반영됨.
- 카드 4에는 실제 결함 3개 이상의 수정 전후를 제출문에 적도록 명시되어 있어 최종 자료에도 포함할 것.
- 과제 승인 흐름: 제출 → 강사 승인 → 마스터 승인. 승인 전 다음 과제가 잠김.


## 로컬 구현 후 확인 메모

로컬 확인은 공개 배포의 통과를 의미하지 않습니다. 검사 수치와 증거는 qa/checklist.md에 있습니다. C09는 별도 근거 자료 대기입니다. C08의 세 번째 경험은 학습 결과에 대한 사용자 설명이며, 구체적인 검사 산출물은 후속 자료로 보강합니다.
