## D01 · 1366×768에서 근거 영역이 첫 화면 밖으로 밀림

- 관련: T01-C10.
- 재현: 기준 해상도로 열고 최상단으로 이동.
- 수정 전: 근거 영역 시작 792.59px, 하단 887.78px로 높이 768px를 벗어남.
- 원인: 데스크톱 소개 영역과 카드 여백의 누적 높이.
- 수정: 801~1599px에서 헤더·제목·여백을 조정.
- 수정 후: 근거 영역 시작 679.77px, 하단 762.95px. 소개·활동·근거 모두 초기 화면에 표시됨.
- 증거: evidence/before/1366-layout.png → evidence/after/1366-full.png 및 browser-results.json.

## D02 · 경험 펼치기 컨트롤의 접근 가능한 이름이 모두 같음

- 관련: T01-C14/C21의 사용성 개선.
- 수정 전: 컨트롤 3개 모두 ‘상황과 행동 살펴보기’로 읽혀 독립된 컨트롤 목록에서 경험 구분이 어려움.
- 원인: 공통 문구만 사용한 summary 요소.
- 수정: 각 summary의 aria-label에 해당 경험 제목과 기존 동작 문구를 포함.
- 수정 후: 3개의 서로 다른 이름을 접근성 트리에서 확인. 마우스·Enter·Space 동작도 모두 확인.
- 증거: evidence/before/observations.md, evidence/after/browser-results.json. 자동 검사로 고유 이름 회귀 방지.

## D03 · 삭제한 공개 자료가 재빌드 결과에 남음

- 관련: T01-C24 및 배포물 공개 범위 관리.
- 수정 전: public의 자료를 삭제해도 기존 dist에 복사된 파일이 남음.
- 재현: 격리된 임시 폴더에 테스트 전용 자료 추가 → 빌드 → 원본 삭제 → 재빌드. dist의 자료 접근이 여전히 성공함.
- 실제 사적 자료나 비밀값을 사용하지 않았음.
- 원인: 빌드가 기존 출력에 파일을 복사하기만 함.
- 수정: 현재 작업 폴더 바로 아래 dist 경로임을 확인하고 심볼릭 링크를 거부한 뒤 출력 폴더를 새로 생성.
- 수정 후: 같은 회귀 검사에서 삭제 파일 접근이 실패하며 테스트 통과. 전체 검사 6개 통과, 빌드 성공.
- 증거: evidence/before/observations.md, tests/acceptance.spec.js.
