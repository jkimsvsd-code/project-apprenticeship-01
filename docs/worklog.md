### 초기화·검증 결과

- Git: `git init -b main` 완료. 첫 커밋과 원격 연결은 아직 없음.
- 의존성: 외부 패키지 없이 package-lock.json 생성 완료.
- `npm run build`: 성공. dist에 사이트 파일만 생성.
- `npm test`: 실행 성공, 통과 0 / 실패 0 / TODO 3. 기능 검증 완료를 뜻하지 않음.
- 브라우저 화면·접근성·공개 URL 검사: 아직 미실시.
