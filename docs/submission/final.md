# 과제1 최종 제출 초안

상태: 로컬 구현·검증 완료, 공개 배포·근거 자료·소스 고정 URL 대기. 아직 제출하지 않습니다.

- 결과물 공개 URL: 미정
- 소스 고정 URL (full commit): 미정
- 실제 배포 코드 SHA: 미정
- 새 시크릿 창 접근 확인: 공개 배포 후 실시

## 짧은 확인 방법 4줄

1. 어디로 가나요: 최종 공개 URL의 ‘경험에서 찾은 세 가지 태도’로 이동합니다. 현재 로컬 주소는 http://localhost:5173/ 입니다.
2. 3단계 이내 무엇을 하나요: 경험 카드의 ‘상황과 행동 살펴보기’를 찾습니다 → 클릭하거나 Tab으로 이동해 Enter/Space를 누릅니다 → 다시 눌러 닫습니다.
3. 무엇이 보이면 통과인가요: 해당 경험의 상황·내가 한 일·결과와 남은 확인이 펼쳐지고 다시 닫히며, 키보드 초점이 보입니다.
4. 안 될 때 무엇이 보이나요: 내용이 펼쳐지지 않거나, 키보드 초점이 보이지 않거나, 다른 경험이 열리면 실패입니다.

## AI와 내 판단 3줄

1. AI에게 맡긴 일: 구조·문구 초안·화면 구현·검증·문서 작성.
2. 내가 직접 판단한 일: 별명 J, 인프라·AI 보안 관심 분야, 독자와 분위기, 실제 경험 3개, 이메일·실명·전화번호 비공개, 근거 자료 추후 제공.
3. AI 제안을 따르지 않은 일 (없으면 이유): 최종 제출 전에 사용자 확인 필요. 임의로 이유를 작성하지 않음.

## 실제 결함 수정 전후

1. 1366×768 첫 화면에서 근거 영역이 792.59px 아래에 위치 → 상단·카드 여백 조정 후 근거 영역 하단 762.95px로 첫 화면에 포함.
2. 펼치기 컨트롤 3개의 접근 가능한 이름이 동일 → 경험 제목을 포함한 고유 이름 적용, 마우스·키보드 동작 재검증.
3. 삭제한 공개 자료가 dist에 남음 → 출력 경로 검증 후 새로 빌드, 동일 재현 검사 통과.
