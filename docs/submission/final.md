## 확인 방법 4줄

1. 위치: 결과물 URL을 열고 ‘경험에서 찾은 세 가지 태도’ 영역으로 이동합니다.
2. 행동: 경험의 ‘상황과 행동 살펴보기’를 찾기 → 클릭하거나 Tab으로 이동해 Enter 또는 Space 누르기 → 같은 버튼을 다시 눌러 닫기.
3. 통과 모습: 선택한 경험의 ‘상황·내가 한 일·결과와 남은 확인’이 펼쳐졌다 닫히며, 키보드로 이동할 때 초점 표시가 보입니다.
4. 실패 모습: 내용이 열리거나 닫히지 않거나, 다른 경험이 열리거나, 키보드 초점이 보이지 않으면 실패입니다.

## AI와 내 판단 3줄

1. AI에게 맡긴 일: 저장소 구조와 문구 초안 작성, 화면·상호작용 구현, 접근성·화면·빌드 검사, GitHub·Vercel 배포와 과정 기록을 맡겼습니다.
2. 내가 직접 판단한 일: 공개 이름 J, 인프라·AI 보안이라는 관심 분야, 독자와 차분한 분위기, 소개할 실제 경험 3개, 이메일·실명·전화번호 비공개와 근거 자료의 추후 제공을 정했습니다.
3. AI 제안을 따르지 않은 일: 처음 Workbench에서 배포 방법으로 GitHub Pages를 제안받았지만, GitHub와 배포 서비스를 분리해 활용하기 위해 Vercel 배포를 선택했습니다.

## 실제 결함 수정 전후 (제출 내용에 함께 포함)

1. 1366×768 첫 화면에서 근거 영역이 792.59px 아래에 위치했습니다. 상단·카드 여백을 조정한 뒤 근거 영역 하단이 762.95px에 들어왔습니다. 실제 근거를 추가하면 재검사합니다.
2. 경험 펼치기 컨트롤 3개의 접근 가능한 이름이 같았습니다. 경험 제목을 포함한 고유 이름으로 바꾸고 마우스·Enter·Space 동작을 확인했습니다.
3. 공개 자료를 삭제해도 이전 dist 파일이 재빌드에 남았습니다. 출력 경로를 검증하고 새로 빌드하도록 고친 뒤 같은 재현 검사가 통과했습니다.
